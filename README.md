# LibreTV 电视端订阅（TVBox 用）

- `tvbox.json` — TVBox 配置订阅地址，13 个点播站 + 电视剧/电影/动漫/综艺等分类
- `live.m3u` — 精选直播清单（270+ 频道，全部经过分片级测活）

订阅地址（任选其一，推荐 jsDelivr）：

- jsDelivr: `https://cdn.jsdelivr.net/gh/cailipc/libretv-tvbox@main/tvbox.json`
- 直连备用: `https://raw.githubusercontent.com/cailipc/libretv-tvbox/main/tvbox.json`

在电视上的 TVBox / 影视仓里：设置 → 配置地址 → 粘贴上面的订阅链接 → 确定，重启即可。
